# Photo Tile Maker

複数の写真（最大20枚）を、色・明るさ・構図を読み取りながら自動でタイル状に並べるアプリです。
写真に撮影データ入りのフレームを付ける [Exif Frame Maker](https://rivrice.github.io/exif-frame-maker/) の姉妹アプリです。

- **ブラウザ版**：https://rivrice.github.io/Photo-tile-maker/
- **Android版**：[Releases](https://github.com/Rivrice/Photo-tile-maker/releases/latest) から `photo-tile-maker.apk` をダウンロード

## できること

- **9種類の自動レイアウト**：モザイク／行そろえ／グリッド／マソンリー／主役＋脇役／黄金スパイラル／ハニカム／ドット／散らし。「別のパターンにする」で配置を変えられます
- **カスタムレイアウト作成**：レイアウト一覧の「カスタム作成」から、自分でレイアウトを作って保存できます（端末内に保存）
  - 四角・円・三角・六角のマスを置き、選択して移動・拡大・回転・複製・削除。元に戻す／やり直しにも対応
  - ダイレクトレイアウト：なぞった線に沿ってマスを区切る、なぞった線に沿って図形を並べる
  - 既存のレイアウトや保存したレイアウトをひな形にして編集
- **斜めカット・すき間・余白・角丸**：タイルの形を自由に調整
- **ドラッグで直感操作**：プレビューの写真をドラッグして入れ替え
- **2本指で拡大・長押しで全画面**：プレビュー全体を2本指で拡大、写真を長押しで全画面表示
- **写真の調整**：サイズ・回転（自由な角度）をスライダーで。位置は「左／右」「上／下」の微調整ダイヤルで（動かせる方向だけ表示）
- **グラデーション配置**：明るさ・色相・鮮やかさ・色の近さを基準に、左→右／上→下／斜め／中心から のグラデーションになるよう配置
- **並べ替え**：構図ごと・撮影日時・ファイル名・シャッフル・逆順
- **おまかせ配置**：縦長のタイルには縦長の写真、横長には横長の写真を自動で割り当て
- **構図の自動検出**：日の丸・三分割・黄金比・対角線・水平線・シンメトリーを読み取り、
  - 構図を崩さないようにトリミング
  - タイルの中に図形を組み込み（ガイド線／アクセント／切り抜き）。図形は元の写真を基準に描くので、どのタイルに入れても形が崩れません
  - 検出精度が50%以下の写真は、初期設定では図形を描きません（設定で表示も可能）
  - 構図を手動で選んだ写真は、「図形の操作」で図形の位置・大きさ・角度を調整できます
- **背景色**：定番色のほか、読み込んだ写真から抽出した色
- **書き出し**：JPEG / PNG / WebP、長辺 1080〜4096px

## 使い方

1. 「写真を追加」から写真を選びます（最大20枚、スマホは下の「＋」から）
2. 「レイアウト」でタイルの並べ方を選びます
3. 「並べ替え」「構図」「スタイル」で好みに調整します
4. 「保存」から画像を書き出します

## Android版のインストール

1. [最新のリリース](https://github.com/Rivrice/Photo-tile-maker/releases/latest)から `photo-tile-maker.apk` をスマホでダウンロード
2. ファイルを開いてインストール（「提供元不明のアプリ」の許可を求められたら許可）

新しいバージョンは、同じ手順で上書きインストールできます。

## プライバシー

写真の読み込み・解析・書き出しはすべてお使いの端末内で行われ、外部に送信されることはありません。
書き出した画像には位置情報などのExif情報は残りません。アクセス解析や広告も使用していません。
